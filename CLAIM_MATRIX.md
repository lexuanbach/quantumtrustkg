# Paper-to-artifact claim matrix

This matrix covers every quantitative claim of the camera-ready paper (`paper/camera-ready.pdf`) that comes from a result file, and the headline claims and result tables of the extended version (`paper/extended.pdf`). Labels refer to the current PDFs. `CR` is the camera-ready and `EXT` the extended version. `scripts/check-claims.py` holds the same list and checks each value. `python3 scripts/check-claims.py --markdown` prints the table below.

Columns:

- **Paper tag** is the tag printed next to the number in the paper: [M] measured, [P] modelled, or untagged. For untagged numbers the kind of evidence is given in brackets.
- **Evidence class** says how the artifact backs the number: regenerated by a deterministic harness, replayed from the canonical record of the archived in-cluster run (H1) or of the cost model, measured on the host (timing), computed from the committed Alibaba edge lists, or read from code.
- **Result file and key** is a file in `implementation/experiments/outputs/processed/` (unless another path is given) and the row and column read.
- **Status** is the result of `check-claims.py` on the committed files. PASS means the file value rounds to the paper value. WARN (a known difference) and UNTRACED (no file holds the value) are no longer used after the corrections of 2026-09-25, and `check-claims.py` still supports them.

Summary: 74 claim groups, 414 values. PASS 74, WARN 0, UNTRACED 0, FAIL 0. Figures: Fig. 1 is a diagram without data. Fig. 2 is drawn by `scripts/make_camera_figures.py` from the files of claims C24 to C33 and E03. Table 1 is printed by `scripts/make_tables.py`. Table 2 is a qualitative comparison without data.
